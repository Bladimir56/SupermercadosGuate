# Reglas del proyecto

- La base de datos objetivo es SQL Server.
- La aplicación objetivo es ASP.NET Core MVC.
- El acceso a datos debe usar ADO.NET con SQL parametrizado.
- Es obligatorio leer el script SQL vigente antes de trabajar con la base de datos.
- Está prohibido modificar el esquema sin permiso explícito.
- Este documento no autoriza implementar login, panel, dashboard ni CRUD.
- No se deben inventar tablas, credenciales ni datos de acceso.
- Los comandos ejecutados deben registrarse en `docs/COMANDOS_RAPIDOS.md` sin secretos.
- La fuente de verdad del esquema es el script SQL vigente del grupo.
- El diseño oficial de la interfaz es la imagen PNG ubicada en `docs/prototipos/0. Diseño Oficial.png`.
- La UI debe usar blanco y azul, carrito azul, menú lateral, KPI y formularios Agregar/Editar en modales.
- Los flujos encabezado-detalle deben usar un modal amplio.
- Los CRUD se implementarán después de la aprobación correspondiente.
