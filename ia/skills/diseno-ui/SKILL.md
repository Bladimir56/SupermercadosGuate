# Diseño de UI

Skill inicial para documentar interfaces del proyecto cuando se aprueben los flujos y requisitos.

- Mantener el alcance en ASP.NET Core MVC.
- No implementar login, panel ni dashboard sin solicitud y aprobación explícitas.
- No inventar entidades, datos ni permisos.
- Consultar el esquema SQL vigente antes de diseñar pantallas dependientes de datos.
