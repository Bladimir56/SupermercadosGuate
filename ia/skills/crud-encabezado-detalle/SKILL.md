# CRUD encabezado-detalle

Skill inicial para documentar operaciones encabezado-detalle cuando exista un esquema aprobado.

- Leer primero el script SQL vigente.
- Usar transacciones y SQL parametrizado cuando el diseño aprobado lo requiera.
- No inventar tablas, columnas, credenciales ni reglas de negocio.
- Requerir aprobación antes de modificar el esquema.
